# Task Manager

A simple and clean **Task Manager** built with **React + TypeScript** as a practical project for improving TypeScript and React skills.

## ✨ Features

* Add new tasks
* Set a due date for each task
* Manage task status:

  * Todo
  * In Progress
  * Done
* Filter tasks by status
* Delete tasks
* Store tasks using Local Storage
* Responsive design
* Date picker for selecting task dates

## 🛠️ Tech Stack

* **React 19**
* **TypeScript**
* **Vite**
* **Tailwind CSS**
* **Base UI**
* **shadcn/ui**
* **Lucide React**
* **React Icons**
* **React Day Picker**
* **date-fns**
* **Geist Font**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/task-manager.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
